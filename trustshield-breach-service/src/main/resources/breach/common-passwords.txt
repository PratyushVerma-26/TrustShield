# Bundled common-password list — offline fallback for the breach monitor.
#
# WHAT THIS IS
#   A small, hand-assembled list of passwords that are widely documented as weak
#   and heavily reused: keyboard walks, single dictionary words, years, and the
#   perennial "password" family. It exists so the breach monitor can demonstrate
#   a real EXPOSED verdict with no network access and no API key.
#
# WHAT THIS IS NOT
#   It is NOT a breach corpus, and it is NOT a ranked frequency list. It carries
#   no occurrence counts, and the service must not report any for a match found
#   here — CommonPasswordCatalog returns "count unknown" precisely so that no
#   number gets invented. The authoritative source is the Pwned Passwords range
#   API, which does report real counts; enable it with
#   trustshield.breach.pwned-passwords.enabled=true.
#
#   Because the list is short, a password absent from it means almost nothing.
#   That is why a NOT_FOUND from this source alone is reported as inconclusive
#   rather than as "safe".
#
# FORMAT
#   One password per line. Blank lines and lines beginning with # are ignored.
#   Stored in plaintext deliberately: a reviewer can see exactly what is being
#   matched, which is not possible if the file holds only hashes. These strings
#   are among the most-published in computing and are not secrets.
#
# The service SHA-1s each entry at startup and keeps only the digests in memory.
